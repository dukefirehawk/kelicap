# Core Components

- **4.1 Defining Components**
  - `@Component` decorator properties (`selector`, `template`, `templateUrl`, `styleUrls`, `directives`, `providers`).
  - Component lifecycle hooks (`OnInit`, `OnDestroy`, `DoCheck`, `AfterViewInit`, `AfterContentInit`).
- **4.2 Component Inputs & Outputs**
  - Passing data in with `@Input()`.
  - Emitting events with `@Output()` and `StreamController` / `EventEmitter`.
- **4.3 View Encapsulation & Styling**
  - `ViewEncapsulation.emulated`, `none`.
  - Scoped CSS rules and global style imports.
- **4.4 Element & View Querying**
  - Accessing child elements using `@ViewChild` and `@ViewChildren`.
  - Accessing projected content using `@ContentChild` and `@ContentChildren`.
  - Working with `ElementRef`, `TemplateRef`, and `ViewContainerRef`.
