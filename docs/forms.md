# Forms (`kelicap_forms`)

- **8.1 Template-Driven Forms**
  - `ngForm`, `ngModel`, `ngModelGroup`.
  - User interaction tracking (`touched`, `dirty`, `valid`, `invalid`).
- **8.2 Reactive / Model-Driven Forms**
  - `ControlGroup`, `Control`, `ControlArray`.
  - Dynamic form construction with `FormBuilder`.
- **8.3 Form Validation**
  - Built-in validators (`Validators.required`, `Validators.minLength`, `Validators.pattern`).
  - Custom synchronous and asynchronous validators.
- **8.4 Custom Control Value Accessors**
  - Implementing `ControlValueAccessor` interface for custom form components.
