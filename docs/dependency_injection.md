
# Dependency Injection

## The Kelicap DI Engine

- `@Injectable()` annotation.
- Hierarchical injectors (Application Injector, Module Injector, Component Injector).

## Configuring Providers

- Class providers (`ClassProvider`).
- Value providers (`ValueProvider`).
- Factory providers (`FactoryProvider`).
- Existing/Alias providers (`ExistingProvider`).

## Injecting Dependencies

- Constructor injection.
- Resolution modifiers (`@Optional()`, `@Self()`, `@SkipSelf()`, `@Host()`).
