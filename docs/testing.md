
# Testing

- **11.1 Testing Setup**
  - Configuring `pubspec.yaml` for testing.
  - Running unit and component tests with `dart test -p chrome`.
- **11.2 Component Test Bed (`ComponentTestBed`)**
  - Initializing component fixtures (`ComponentFixture`).
  - Triggering change detection during tests (`fixture.detectChanges()`).
- **11.3 Interacting with DOM in Tests**
  - Querying native elements using CSS selectors.
  - Simulating user clicks and text input events.
- **11.4 Async & Service Mocking**
  - Mocking injected dependencies and network calls.
