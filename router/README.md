# Router for Kelicap

![Pub Version (including pre-releases)](https://img.shields.io/pub/v/kelicap_router?include_prereleases)
[![Null Safety](https://img.shields.io/badge/null-safety-brightgreen)](https://dart.dev/null-safety)
[![License](https://img.shields.io/github/license/dukefirehawk/kelicap)](https://github.com/dukefirehawk/kelicap/blob/master/LICENSE)

This package provides a feature-rich routing library for single-page applications, offering declarative routing, dynamic route matching, route parameters and nested views for Kelicap applications. It enables navigation from one view to the next as users perform tasks.
